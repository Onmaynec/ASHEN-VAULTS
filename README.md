# ASHEN VAULTS

**Версия исходников: 0.4.0 «Бездна пробуждается»** · Unreal Engine **4.27** · Windows / C++ · бюджет **0 ₽**

Мрачный 2D top-down roguelite с интенсивным Hack & Slash и самостоятельной пиксельной стилистикой. По темпу и ракурсу ориентируемся на игры жанра вроде Pocket Rogues, но не копируем чужие ассеты.

> **Текущий статус:** большая контентная версия существует **в исходном коде**. Проект ещё не скомпилирован и не запущен в настоящем Unreal Engine 4.27 / Windows; готовой `.exe`-сборки нет. Графика временно создаётся C++-кодом и выводится через Canvas. Плагин Paper2D включён, но настоящие TileMap/Flipbook и авторские анимации пока не созданы.

## Что появилось в 0.4.0

- **6 этажей, 3 разных биома:** Пепельный склеп (1–2), Споровые пустоты (3–4), Огненная кузня (5–6).
- **3 босса:** Костяной регент на втором этаже, Тиран кузни на четвёртом, Хранитель хранилища на шестом. Каждый имеет свою основу боя и ускоренную вторую фазу.
- **Новые враги:** могильная гончая, споромант, шлаковый голем и пустотный огонёк. Вместе с предыдущими противниками и мимиком — **8 обычных архетипов** в исходном коде.
- **6 древних реликвий:** выбирайте одну из трёх после каждого босса; эффекты на восстановление HP, защиту, метательные клинки, вихрь, рывок и доход.
- **Странствующий торговец:** безопасная комната на каждом этаже, товары за золото — лечение, заточка клинка, зелье.
- **Опасности биомов:** ядовитые споры и раскалённые области с временными отрицательными эффектами. Зелье очищает оба эффекта.
- **Разрушаемые урны и ящики:** разбиваются оружием и оставляют полезную добычу.
- **Новые процедурные 16×16-пиксельные изображения**, оформление биомов, экраны торговца и реликвий, полоса здоровья босса и индикаторы эффектов.

### Исправления

В исходниках переработаны удары и снаряды через стены; линии видимости теперь запрещают попадание сквозь диагональные щели. Добавлена защита от перезаписи игрового состояния во время выбора реликвии, ограничена частота рывка, продавец размещается в безопасной комнате, а покупка лечения при полном здоровье не списывает золото.

Полный перечень: **[CHANGELOG.md](CHANGELOG.md)** и **[пост с описанием 0.4.0](Docs/RELEASES/v0.4.0.md)**.

## Запуск и проверка

1. Установите **Unreal Engine 4.27** и **Visual Studio 2019** с workload «Разработка игр на C++» и Windows SDK.
2. Выполните `git clone https://github.com/Onmaynec/ASHEN-VAULTS.git` либо `git pull origin main` в существующем клоне.
3. В проводнике: `AshenVaults.uproject` → **Generate Visual Studio project files**.
4. Откройте `AshenVaults.sln`, выберите **Development Editor | Win64**, соберите проект. Альтернатива: откройте `.uproject` через UE4.27 и запустите компиляцию модуля.
5. В UE4 нажмите **Play → Standalone Game**; если управление не реагирует, кликните в игровое окно.

Стартовая карта — встроенная `/Engine/Maps/Entry`; всё окружение первой версии рисуется через игровой HUD.

**Проверки без UE4:** можно скомпилировать исходные модули данных и навигации через `g++` с минимальной заменой `CoreMinimal.h`, запустив:
```bash
bash Tests/Standalone/run.sh
bash Tests/Standalone/run_content.sh
```
Оба теста прошли в среде разработки при `-std=c++14 -Wall -Wextra -Werror -pedantic`; SHA исходников, тестов и shim был сопоставлен с GitHub. Это **не проверка полного игрового модуля на UE4**.

## Управление

| Действие | Клавиши |
| --- | --- |
| Движение / прицеливание | WASD / мышь |
| Удары мечом | ЛКМ (можно удерживать) |
| Вихревой удар | Q или ПКМ (32 выносливости, с реликвией — 24) |
| Метательный клинок | R (18 выносливости, с реликвией усилен) |
| Рывок | Пробел (23 выносливости, перезарядка 0,7 с) |
| Использовать зелье | E (лечит 42 HP, снимает яд и горение) |
| Торговец / алтарь / сундук / лестница | F рядом с объектом |
| Купить предмет / выбрать улучшение / реликвию | 1, 2 или 3 |
| Закрыть магазин | F или Esc |
| Пауза | P или Esc вне магазина/экранов выбора |
| Новый забег после смерти/победы | Enter |
| Повторить seed после смерти/победы | R |

**Цель:** пройти шесть этажей, собирать реликвии и предметы, побеждать боссов и зачистить последний этаж. Туман войны скрывает неизвестные комнаты, а неоткрытые сундуки могут содержать мимиков. Выход работает после победы над всеми появившимися врагами.

## Основные файлы

- `AVGameMode.h/.cpp` — игровое состояние, бои, генерация, способности, предметы, боссы, торговцы и переходы.
- `AVContent.h/.cpp` — таблицы характеристик, наборы врагов, биомы, боссы, цены.
- `AVDungeonNavigation.h/.cpp` — открытие карты, line of sight, BFS-пути.
- `AVHUD.h/.cpp` — пиксельные текстуры, тайлы, мини-карта, интерфейс.
- `AVSaveGame.h/.cpp` — рекорды одиночных забегов.
- `Docs/RELEASES/` — описание каждой версии.
- `Docs/TEST_PLAN.md` — обязательные ручные проверки до игрового релиза.

## Что ещё не готово
