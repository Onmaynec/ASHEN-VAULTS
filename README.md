# ASHEN VAULTS

**2D Top-Down Action Roguelite · Unreal Engine 4.27 · Windows · C++**

ASHEN VAULTS — мрачная игра о вылазках из подземного поселения в бесконечные подземелья. В каждом забеге игрок сражается с монстрами, находит снаряжение и реликвии, проходит этаж за этажом и встречает босса в конце биома. Между вылазками можно вернуться в поселение, улучшить экипировку и подготовиться к следующему спуску.

Проект вдохновлён динамикой Pocket Rogues, но развивается как самостоятельная игра со своими механиками, противниками и оформлением.

> **Состояние проекта:** в `main` находятся исходники до **v1.1.0 «Равновесие глубин»**. Автономные тесты отдельных C++-модулей запускались в GitHub Actions. **Полная сборка в UE4.27 на Windows, запуск игры и готовый EXE пока не подтверждены.** Поэтому v1.0.0 — номер версии исходников, а не объявление о состоявшемся публичном релизе.

## Обновление 1.1.0 — «Равновесие глубин»

Основное изменение — перебалансировка роста противников с глубиной. Убрано двойное увеличение HP от этажа и уровня; рост урона за уровень снижен с **8,5% до 6,5%**. Число бандитов в одном лагере ограничено **3–8**.

Исправлены призыв подкрепления боссами, лечение погибших союзников, выбор целей у враждебных фракций, масштабирование мимиков **и действие бонусов скорости атаки** на героев ближнего боя. Проверки расстояний в бою упрощены. Характеристики четырёх героев, 42 предмета и 39 навыков сохранены; их ограничения дополнительно проверяются автономными тестами.

[Полный список изменений v1.1.0](Docs/RELEASES/v1.1.0.md). **Графика в этой версии не изменялась.** Полная сборка Unreal Engine 4.27 и реальное балансировочное прохождение ещё требуются.

## Игровой процесс

- **Бесконечный спуск.** Каждый биом занимает пять этажей. На пятом этаже — арена босса; после четвёртого биома цикл начинается заново с увеличением глубины.
- **Четыре героя:** Страж, Дуэлянт, Арканист и Стрелок. У каждого свои базовые характеристики, атаки и классовая ветвь навыков.
- **Сражения в реальном времени.** Ближние удары, вихревые атаки, метательные клинки, стрелы, пробивные выстрелы, рывки, ловушки и способности противников.
- **Развитие персонажа.** Уровни, улучшения характеристик, 39 узлов навыков, реликвии, оружие, броня и аксессуары.
- **Экипировка и добыча.** 42 предмета в каталоге v0.9.0: 10 оружий, 25 элементов брони и семь аксессуаров. Восемь слотов экипировки и рюкзак на 48 вещей.
- **Лагеря и возвращение домой.** Мирный лагерь с торговцем, кузнецом и путником отличается от враждебного лагеря бандитов. Путник возвращает в подземный город: запасные вещи продаются, надетая экипировка остаётся.
- **Процедурные этажи.** Комнаты, коридоры, опасности, тайники и противники определяются глубиной и seed забега. В Чёрном бастионе используется отдельная крепостная планировка.

### Биомы

| Этажи цикла | Биом | Основные особенности |
| --- | --- | --- |
| 1–5 | Пепельные склепы | Старые захоронения, каменные коридоры, скелеты и погребальные ловушки |
| 6–10 | Споровые пустоты | Пещерные залы, ядовитые участки, споровые существа |
| 11–15 | Пламенная кузня | Раскалённые области, механизмы и тяжёлые противники |
| 16–20 | Чёрный бастион | Крепостные крылья, галереи, вооружённые стражи и новые ловушки |

После двадцатого этажа цикл повторяется. Номер этажа продолжает увеличиваться, а вместе с глубиной растёт уровень противников.

## Управление

| Действие | Управление |
| --- | --- |
| Движение | WASD |
| Прицеливание | Мышь |
| Обычная атака / выстрел Стрелка | ЛКМ |
| Вихрь / залп Стрелка | Q или ПКМ |
| Метательный клинок / пробивной выстрел Стрелка | R |
| Рывок | Пробел |
| Взаимодействие с миром, торговцем и сундуками | E |
| Лечебное зелье | F |
| Инвентарь | I или Tab |
| Дерево навыков | K |
| Навигация в инвентаре и навыках | Стрелки; Enter или E для выбора |
| Снять предмет из слота | 1–8 в инвентаре |
| Сбросить навыки в поселении или лагере | Backspace в дереве |
| Пауза | Esc или P |
| Качество эффектов | F3 |
| Сменить класс и начать новый забег | H во время игры |

Клавиша **H** начинает новый забег за следующий класс. В меню выбора героя класс можно выбрать до начала экспедиции. Пункты меню и доступные действия зависят от текущего состояния игры.

## Структура проекта

| Путь | Содержимое |
| --- | --- |
| `Source/AshenVaults/AVGameMode.*` | Основной игровой цикл, персонажи, бой, генерация, взаимодействия и сохранение |
| `Source/AshenVaults/AVContent.*` | Параметры классов, противников, боссов и биомов |
| `Source/AshenVaults/AVEquipment.*`, `AVSkills.*` | Снаряжение, бонусы и навыки |
| `Source/AshenVaults/AVDungeonNavigation.*` | Путь к цели, обзор и туман войны |
| `Source/AshenVaults/AVHUD*.cpp` | Отрисовка мира, боевых эффектов, инвентаря и дерева навыков |
| `Source/AshenVaults/AVFrontendWidget.*` | Главное меню на UMG |
| `Content/AVVisuals/` | PNG-атласы, иконки и элементы окружения |
| `Tests/Standalone/` | Тесты независимых C++-модулей |
| `Docs/RELEASES/` | Изменения по версиям |

**Текущая графика:** атласы персонажей, предметов и биомов загружаются из PNG. Основная отрисовка мира пока использует Canvas; главное меню создано на UMG. Полный переход на Paper2D Flipbook/TileMap, готовые Niagara-системы и игровые UE-материалы ещё не завершён. Файлы из `Content/AVVisuals` — текущие технические ресурсы, а не утверждённый финальный художественный стиль.

## Сборка из исходников

Для работы потребуется **Unreal Engine 4.27**, Windows SDK и Visual Studio с поддержкой C++ для Unreal Engine.

1. Клонируйте репозиторий: `git clone https://github.com/Onmaynec/ASHEN-VAULTS.git`.
2. Сгенерируйте файлы проекта через `AshenVaults.uproject`.
3. Соберите `Development Editor | Win64` и откройте проект в UE4.27.
4. Проверьте запуск, выбор героя, инвентарь, сохранения и переход между этажами.

Эти шаги описывают предполагаемый порядок сборки. **Подтверждённого успешного прогона UE4.27/Win64 пока нет.** Возможные ошибки сборки и запуска отслеживаются в [Issue #1](https://github.com/Onmaynec/ASHEN-VAULTS/issues/1) и [Issue #22](https://github.com/Onmaynec/ASHEN-VAULTS/issues/22).

### Автономные проверки

Для отдельных модулей доступны:

```bash
bash Tests/Standalone/run.sh
bash Tests/Standalone/run_content.sh
bash Tests/Standalone/run_art.sh
bash Tests/Standalone/run_v09.sh
bash Tests/Standalone/run_fortress.sh
```

Они проверяют навигацию, данные контента, генерацию и другие независимые части C++. **Эти проверки не компилируют полноценный игровой модуль Unreal Engine.**
