# ASHEN VAULTS

> **[ПРОЕКТ]** Мрачный 2D top-down roguelite с динамическим ближним боем, случайными подземельями и пиксельной графикой. Вдохновение по темпу и перспективе — Pocket Rogues; все игровые ресурсы создаются самостоятельно.

## [СТАТУС] Версия 0.2.0 — «Эхо глубин» (исходники)

Проект разрабатывается под **Unreal Engine 4.27** на C++. В проекте включён модуль **Paper2D**. Первый прототип полностью рисует пиксельные текстуры процедурно и показывает их через Unreal Canvas: это позволяет запускать игру без импортированных `.uasset`. Перенос мира на Paper2D Sprite/Flipbook/TileMap — следующий этап, а не реализованная сейчас возможность.

**Реализовано в исходниках:** генератор комнат и коридоров, 3 этажа, управление и прицеливание мышью, удержание ЛКМ для серии ударов, вихревой удар, рывок, зелья, три вида обычных врагов, элитные модификации и финальный босс с дополнительной фазой, ловушки, алтари, осколки урона, комбо, опыт и выбор улучшений, мини-карта, HUD, экраны смерти/победы, локальные рекорды и повтор забега с тем же seed. Подробности: [CHANGELOG.md](CHANGELOG.md) и [заметки к версии 0.2.0](Docs/RELEASES/v0.2.0.md).

**Не реализовано:** сетевой кооператив, подземный город, полноценная экипировка/инвентарь, сюжет, звук, полноценная карта Paper2D, импортированный авторский pixel art и релизная Windows-сборка. Никакого EXE пока нет: требуется реальная компиляция в установленной UE4.27.

## [ЗАПУСК]

1. Установите **Unreal Engine 4.27** и **Visual Studio 2019** с компонентами «Разработка игр на C++» и Windows SDK.
2. Клонируйте репозиторий, щёлкните правой кнопкой по `AshenVaults.uproject` → **Generate Visual Studio project files**.
3. Откройте `AshenVaults.sln` → конфигурация **Development Editor | Win64** → соберите проект. Либо откройте `.uproject` через UE4.27 и дайте редактору собрать модуль.
4. Нажмите **Play → Standalone Game**. Для Play In Editor нужно кликнуть в игровое окно, чтобы активировать управление.

Стартовая карта: встроенная `/Engine/Maps/Entry`. Она намеренно пустая: прототип отрисовывается через HUD, поэтому отдельный `.umap` для первого запуска не требуется.

## [УПРАВЛЕНИЕ]

| Клавиша | Действие |
| --- | --- |
| WASD | Ходьба |
| Мышь | Прицеливание |
| Левая кнопка мыши (удерживать) | Серия ударов мечом |
| Q / Правая кнопка мыши | Вихревой удар (за выносливость) |
| Пробел | Рывок |
| E | Использовать зелье |
| F | Получить благословение у алтаря / спуститься у лестницы после зачистки |
| 1 / 2 / 3 | Выбрать улучшение при повышении уровня |
| P / Esc | Пауза |
| Enter | Начать новый забег после смерти/победы с новым seed |
| R | Повторить забег с тем же seed после смерти/победы |

Цель забега: зачистить **три этажа**, получить усиления у алтарей, пережить ловушки, победить Хранителя на последнем этаже и активировать лестницу. Seed текущего забега отображается под мини-картой.

## [АРХИТЕКТУРА]

- `AVGameMode` — детерминированная карта, модель забега, ввод, столкновения, атаки, враги, награды, переходы.
- `AVHUD` — 2D-рендерер пиксельных текстур, эффекты, панели, миникарта.
- `AVSaveGame` — рекорды локального одиночного забега.
- `Config/` — старт в чистом мире с нашим игровым режимом.
- `Docs/ROADMAP.md` — план следующей итерации и границы текущего прототипа.
