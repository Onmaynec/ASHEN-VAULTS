# План проверки ASHEN VAULTS 0.2.0

> Это чек-лист ручного QA для UE4.27. Пункты ниже **не отмечены как пройденные**, потому что UE4 и Windows toolchain в среде разработки отсутствуют.

## A. Сборка и старт

- [ ] На Windows с UE4.27 и VS2019: `Development Editor | Win64` собирается без ошибок UHT/C++/linker.
- [ ] `AshenVaults.uproject` открывается; GameMode корректно выбран в Project Settings.
- [ ] Standalone показывает HUD, подземелье, героя и мини-карту (не чёрный экран).
- [ ] В окне 960×540, 1280×720, 1920×1080 текст/спрайты не накладываются друг на друга.

## B. Управление и бой

- [ ] WASD и мышь управляют независимо; герой не проходит через стены и углы.
- [ ] Удержание ЛКМ повторяет атаки не чаще 1 раза за 0,33 секунды.
- [ ] Q/ПКМ тратит выносливость и имеет откат; Space делает рывок и даёт краткую неуязвимость.
- [ ] E тратит зелье только при неполном HP.
- [ ] Обычный враг сначала показывает предупреждение, затем удар; отход и рывок избегают урона.
- [ ] Снаряды не пробивают стены.
- [ ] На финальном этаже при HP босса ниже 50% появляются дополнительные снаряды.

## C. Генерация и прогресс

- [ ] Все комнаты и коридоры достижимы, лестница активируется после победы над всеми врагами.
- [ ] Генерируется алтарь, клавиша F рядом даёт +35 HP / +2 DAMAGE не более одного раза на этаж.
- [ ] Ловушка отмечена, предупреждает и после срабатывания восстанавливается через 2,8 секунды.
- [ ] У элитного врага больше HP, видна золотая метка, после смерти появляется осколок.
- [ ] Каждое пятое убийство в комбо даёт +5 золота; 4,5 секунды без убийств сбрасывают цепочку.
- [ ] После смерти `R` возвращает первую карту того же seed, а `Enter` выдаёт новый seed.
- [ ] Рекорды сохраняются после перезапуска игры.

## D. Регрессии

- [ ] Экран выбора прокачки ставит бой на паузу.
- [ ] На 3-м этаже после убийства босса и остальных врагов `F` у лестницы завершает забег.
- [ ] Esc/P ставит игру на паузу и возобновляет.
- [ ] Нельзя получить отрицательные HP/выносливость, поднять предмет два раза или лечиться без зелий.
- [ ] Локальные сохранения 0.1.0 доступны без удаления старого слота.

## E. Проверки v0.3.0 — «Тени и тайники»

- [ ] При старте видно только начальную часть уровня; неизведанные клетки скрыты на мини-карте.
- [ ] Враги, лут, ловушки и сундуки за стеной не видны, даже если находятся рядом по координатам.
- [ ] Исследованный, но невидимый коридор остаётся затемнённым, не раскрывая живых врагов.
- [ ] На следующем этаже память карты очищается.
- [ ] F у сундука срабатывает однократно; открытая крышка остаётся открытой.
- [ ] Обычный сундук выдаёт награду; сундук-мимик создаёт врага и блокирует лестницу.
- [ ] Враг может обойти изгиб коридора и не застревает перед стеной.
- [ ] R в бою тратит 18 выносливости, даёт снаряд с откатом 0,65 с; нож повреждает врага и не проходит сквозь стены.
- [ ] R на экране смерти/победы запускает тот же seed, не бросая клинок.
- [ ] Отображение на 960×540, 1280×720 и 1920×1080 не обрезает интерфейс.
