# Используемые графические ресурсы

В проекте используются собственные рабочие PNG-ресурсы и материалы из открытых наборов с проверенными условиями использования. Этот документ фиксирует происхождение файлов и зависимости сборки.

## Ресурсы проекта

Каталог `Content/AVVisuals/`:

| Файл | Содержимое |
| --- | --- |
| `Backgrounds/MenuBackdrop.png` | Фон главного меню |
| `Tiles/CryptAtlas.png` | Пол и стены Пепельных склепов |
| `Tiles/SporeAtlas.png` | Пол и стены Споровых пустот |
| `Tiles/FoundryAtlas.png` | Пол и стены Пламенной кузни |
| `Tiles/BastionAtlas.png` | Пол и стены Чёрного бастиона |
| `Characters/HeroAtlas.png` | Кадры четырёх героев |
| `Enemies/EnemyAtlas.png` | Кадры обычных врагов и мини-боссов |
| `Bosses/BossAtlas.png` | Кадры четырёх главных боссов |
| `Icons/EquipmentAtlas.png` | Иконки 42 предметов экипировки |

Эти ресурсы созданы для проекта и хранятся в репозитории. Их наличие не означает, что финальное художественное оформление завершено: часть изображений требует переработки.

## Kenney — Tiny Dungeon

- **Автор:** Kenney.
- **Оригинал:** https://kenney.nl/assets/tiny-dungeon
- **Лицензия:** CC0 1.0 Universal. Изображения разрешено использовать и изменять, в том числе в коммерческих проектах.
- **Зеркало исходного архива:** https://github.com/bill2432/kenney-2d-mirror
- **SHA-256 архива:** `c109438ab06f65fd80f9b2686a4cf9c7c11dc64444b47333ec71d602f8bb5fc7`.
- **Файл в проекте:** `Content/AVVisuals/Kenney/TinyDungeonDecor.png`.

Часть спрайтов из набора перекрашена под палитры четырёх биомов. Воспроизводимая сборка атласа находится в `Tools/Art/vendor_kenney.py`; сведения об источнике также сохранены рядом с файлом в `SOURCE_CC0.txt`. Атрибуция для CC0 не обязательна, но сохранена в документации.

## Движок и инструменты

Unreal Engine 4.27, Paper2D, UMG, Niagara, Slate, ImageWrapper и редакторские инструменты Python применяются в соответствии с условиями их распространения. Встроенный плагин не равен завершённой игровой системе: реальные материалы, Flipbook и Niagara-ресурсы должны быть созданы и подключены отдельно.

## Правила добавления ресурсов

До включения стороннего изображения или звука в репозиторий нужно проверить лицензию, зафиксировать автора и прямую ссылку на источник, сохранить необходимые сведения об атрибуции и указать внесённые изменения. Ресурсы из коммерческих игр без соответствующего разрешения не использовать.
