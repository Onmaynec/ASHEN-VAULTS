# ASHEN VAULTS — v1.0.0 «Перерождение глубин» (исходники)

Статус: крупное визуальное обновление исходного кода UE4.27, **не подтверждённый Windows-билд**. Основной игровой цикл и системы v0.9.0 сохраняются.

## Визуальные ассеты в Content/AVVisuals

- **112 новых процедурно нарисованных PNG-тайлов**: 28 вариантов в каждом из четырёх биомов. Отдельные палитры и рельеф стен/плит.
- **32 авторских кадра героев** (4 персонажа × 8 состояний; 32×32). Движение, покой, атака, рывок; динамический выбор кадра в `AAVHUD`.
- **114 авторских кадров мобов и мини-боссов** (57 ID × 2 кадра; 24×24), с эффектами подготовки атаки, визуальными особенностями врагов.
- **24 кадра основных боссов** (4 босса × 6 кадров; 48×48) с переходом фаз, отдельными размерами и цветным ореолом.
- **42 отдельных иконки экипировки** с прозрачностью, собственным цветом класса и подсветкой редкости.
- Атмосферный пиксельный PNG-фон главного меню.
- **16 дополнительных типов биомного декора**; объекты не блокируют бой, выход и взаимодействие.

Авторские PNG остаются отдельными исходными ресурсами, читаются через `AVImageLoader` (ImageWrapper/BGRA, nearest filter) и попадают в Windows-пакет через `DirectoriesToAlwaysStageAsNonUFS`.

## Бесплатный CC0-арт и лицензии

Подключён Kenney **Tiny Dungeon** (CC0 1.0). GitHub Actions забирает архив из публичного зеркала, строго проверяет SHA-256, извлекает четыре исходных спрайта и делает четыре согласованные по палитрам версии. Результат `Content/AVVisuals/Kenney/TinyDungeonDecor.png` загружается в игровые комнаты, при отсутствии атласа используются авторские процедурные объекты. Происхождение и ссылка на оригинал хранятся в `Content/AVVisuals/Kenney/SOURCE_CC0.txt` и `Docs/ASSET_CREDITS.md`.

Никаких платных ресурсов и ассетов из Pocket Rogues не использовано.

## Главное меню, HUD и навыки

- Новый **главный экран на UMG**, построенный полностью из нативных компонентов без внешнего Blueprint: продолжение контрольной точки, новый забег, выбор четырёх классов, настройки эффектов, переключение оконного/полноэкранного режима, сведения о лицензиях, выход.
- Canvas HUD получил более подробные графические панели экипировки и дерева талантов, цветные иконки предметов, бумажную фигурку героя в слотах и дерево из четырёх ветвей с соединительными линиями, блокировками и описаниями талантов.
- Исходные клавиши боя, управления, торговцев и сохранений не меняются.
- Клавиши **I/Tab** — инвентарь, **K** — дерево навыков.

## Шейдеры, освещение и боевые эффекты

- **Активное пиксельное освещение Canvas**: затемнение при недостатке света, пространственные пулы от факелов, оттенки биомов, ослабление через препятствия, квантованные световые уровни.
- **Активный визуальный слой боя**: искры от попаданий, прерывистые следы снарядов, отдельные цвета для магии и стрел, взмахи оружия, тени от рывка, эффекты смерти и рунические предупреждения боссов.
- Включён встроенный **Niagara**; полноценные `UNiagaraSystem` assets в этой версии **не созданы**: без них эффектов Niagara в собранной игре нет.
- Добавлен редакторский инструмент `Tools/Unreal/BuildVisualMaterials.py`, который создаёт **четыре настоящих UE4.27 Material графа**: пиксельная поверхность, мерцающая эмиссия, хит-флеш и dissolve. Реальный `.uasset` получится **после запуска инструмента в UE4 Editor**. HUD автоматически использует `M_AV_PixelSurface`, если материал существует, иначе рендерит PNG напрямую.
- Дополнительная библиотека `Shaders/AVVisualVFX.ush` содержит пиксельное освещение, палитровый дизеринг, эффект тепла и растворение; библиотека сама по себе **не исполняется на GPU без привязки к материалам**.

## Что не выдаём за готовое

- **Нет проверенной UE4.27/Win64 компиляции и игрового EXE.** Загружать файл `.uproject` и реально запускать движок нужно на компьютере с UE4.27.
- Не переведён весь мир на Paper2D TileMap/Flipbook: игровые спрайты PNG проигрываются через Canvas, хотя Paper2D плагин включён. Это ещё не полноценная архитектура Paper2D.
- Не созданы полноценные `UNiagaraSystem` и `UMG`-экраны для *всего* игрового HUD: главное меню — UMG, инвентарь, таланты и боевые экраны — улучшенный Canvas.
- Не проведена полная регрессия сохранений, баланса, FPS, интерфейсов и проигрывания всех кадров. Тесты уровня исходных данных не заменяют проверку в настоящей UE4.27.

## Порядок запуска на Windows

1. Откройте `AshenVaults.uproject` в Unreal Engine **4.27**. Для Windows рекомендуется Visual Studio 2019 и SDK.
2. **При первом открытии**, с включёнными встроенными `PythonScriptPlugin` и `EditorScriptingUtilities`, запустите:
   ```bat
   UE4Editor-Cmd.exe "PATH\TO\AshenVaults.uproject" -ExecutePythonScript="PATH\TO\Tools\Unreal\BuildVisualMaterials.py"
   ```
   Это создаст материалы в `/Game/AVVisuals/Materials/`; сгенерированные `.uasset` следует сохранить и добавить в репозиторий.
3. Соберите Development Editor | Win64, исправьте UE/UHT ошибки, запустите игру и проверьте главное меню, инвентарь, 4 биома, 4 класса и боссов.
4. Для упаковки используйте Windows Development/Shipping после тестов. PNG из `Content/AVVisuals` должны быть включены в staged non-UFS files.

Итог: `v1.0.0` — реализованный большой визуальный слой в исходниках, но ещё **не готовый верифицированный релиз**.
