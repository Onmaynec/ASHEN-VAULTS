# ASHEN VAULTS — версия 0.3.0 «Тени и тайники»

**Дата:** 8 ноября 2026 года  
**Движок:** Unreal Engine 4.27 / C++  
**Статус:** обновлённые исходники, не проверено сборкой UE4.27.

## Описание обновления

Теперь каждый забег строится вокруг исследования. **Туман войны** скрывает неизвестные комнаты, а мини-карта открывает только те проходы, где побывал герой. Увиденные, но покинутые помещения остаются на карте приглушёнными, не показывая текущее положение противников. Это превращает поиск лестницы, алтаря и ресурсов в отдельную часть прохождения.

В боковых комнатах появились **сундуки**. Подойдите и нажмите **F**, чтобы получить золото и одну награду: лечение, зелье либо осколок урона. У каждого сундука есть **18% шанс оказаться мимиком**. Такой сундук превращается в быстрого противника, которого нужно победить, прежде чем выход с этажа снова будет открыт.

Для боя добавлен **метательный клинок**: во время забега клавиша **R** бросает снаряд по курсору. Стоимость — 18 выносливости, откат — 0,65 секунды, урон — 83% силы меча. Столкновения проверяются вдоль пройденного за кадр отрезка, чтобы быстрый клинок реже пролетал мимо небольшой цели.

Враги используют **BFS-навигацию** по карте: когда прямой путь к герою перекрыт, они выбирают направление по сетке проходов. Это первый этап улучшения ИИ, не финальная система поведения.

## Визуальные изменения

- Программные пиксельные изображения закрытого/открытого сундука, мимика и клинка.
- Тёмные исследованные области, скрытые неисследованные комнаты и минимальная зона прямой видимости.
- Мерцающие декоративные огни на полу.
- Мини-карта теперь показывает разведанные пути, обнаруженные тайники, алтарь и лестницу.
- В HUD обозначены бросок клинка и число оставшихся сундуков.

## Управление

| Действие | Клавиша |
| --- | --- |
| Ходьба / прицеливание | WASD / мышь |
| Ближняя атака / вихрь | ЛКМ / Q или ПКМ |
| Метательный клинок | R во время забега |
| Рывок / зелье | Пробел / E |
| Открыть сундук, алтарь, лестницу | F |
| Повтор seed после смерти/победы | R |
| Новый забег после смерти/победы | Enter |

## Техническое описание

- `Source/AshenVaults/AVDungeonNavigation.h/.cpp` — проверка линии видимости, маски видимости и исследования, BFS-поле и направление преследования.
- `Source/AshenVaults/AVGameMode.h/.cpp` — сундуки, мимики, нож, новые данные для исследования.
- `Source/AshenVaults/AVHUD.cpp` — процедурные текстуры, освещение, туман, мини-карта и подсказки.
- `Config/DefaultGame.ini` — номер версии.
- `CHANGELOG.md`, `README.md`, `Docs/TEST_PLAN.md` — инструкции и план проверки.

## Ограничения

Сетевого кооператива, настоящих Paper2D TileMap/Flipbook, аудио, сюжетного хаба и готового EXE **пока нет**. Компоненты графики рисуются Unreal Canvas, а не через Paper2D-акторы. Скомпилированная Windows-сборка и тестирование в UE4.27 необходимы до любого утверждения о готовом релизе.
