# ASHEN VAULTS — обновление v1.5.0 «Арсенал глубин»

Крупное контентное обновление снаряжения и добычи. В каталоге стало **107 предметов** вместо 42: **30 новых оружий**, **20 предметов брони**, **пять колец** и **десять активных расходников**. Старая нумерация ID 0–41 не меняется. У каждого нового предмета есть собственный ID, русское название, редкость, характеристики и ограничения по классу.

**Графика отложена:** у добавленных предметов сейчас используются технические замены и уже имеющиеся элементы интерфейса. Новые спрайты, эффекты и полноценные анимации будут созданы отдельно. Боевые свойства оружия реализованы в коде, а не изображены на текстурах.

## Редкие особые свойства оружия

Теперь каждый найденный экземпляр оружия может отличаться от других экземпляров **того же самого предмета**. Это не фиксированный бонус всей модели клинка, а случайное свойство найденной вещи.

- Обычные, необычные и редкие предметы дополнительных свойств **не получают**.
- **Эпическое оружие:** вероятность дополнительного свойства **9%**.
- **Легендарное оружие:** вероятность **16%**.
- Одному экземпляру присваивается не более одного свойства из шести.

| Свойство | Эффект |
| --- | --- |
| Охотник склепов | +3 урона по противникам Пепельных склепов |
| Охотник спор | +3 урона по противникам Споровых пустот |
| Охотник кузни | +3 урона по противникам Пламенной кузни |
| Охотник бастиона | +3 урона по противникам Чёрного бастиона |
| Истребитель элиты | +4 урона по элитным врагам |
| Погибель хранителей | +5 урона по боссам |

Бонус добавляется к **фактическому попаданию** (ближнему или дальнему) и не требует отдельного срабатывания кнопки. Свойство сохраняется при надевании, переносе в рюкзак, возвращении в поселение и загрузке сохранения.

### Техническая реализация экземпляров

ID прототипа остаётся в младших разрядах целого числа (`InstanceStride=1024`), номер свойства записывается в старших. Поэтому старые вещи с ID 0–41 продолжают читаться как предметы без случайного свойства. Новые экземпляры сохраняются в существующих массивах `InventoryItems`, `EquipmentSlots` и `Pickup.Amount`. Код не принимает недопустимые свойства на кольцах, броне и расходниках.

## Боевое поведение и сохранения

- `AVItemCombat` содержит десять игровых вариантов атаки и параметры сопротивления ближнему урону.
- Ядовитое и огненное оружие накладывает на врагов временные эффекты, наносящие урон со временем.
- Бонусы от еды и активных настоев участвуют в расчётах урона, защиты, шанса критического попадания, скорости движения и снарядов.
- Модели предметов ограничены классами, требованиями редкости и назначением слота.
- Формат сохранений расширен без перенумерации старых полей: добавлены семь таймеров расходников и три поля статусов для противника. При загрузке старого сохранения эти значения равны нулю.
- `SpawnGearDrop` теперь выбирает активный расходник в **18%** случаев выпадения предмета при подходящих условиях; остальные случаи отведены экипировке. Редкость и доступная глубина по-прежнему ограничивают выбор.

## Проверки и ограничения

Добавлены регрессионные тесты каталога, вероятностей свойств, кодирования/декодирования экземпляров, классовых ограничений и параметров боевых профилей. Проверки включены в GitHub Actions.

**Для полноценной приёмки требуется UE4.27/Win64:** подтвердить применение предметов из инвентаря, изменения атак, длительность статусов и бафов, совместимость старых сохранений и сбалансированность добычи. Запуск полного игрового модуля в редакторе не заменяется автономными C++-тестами.
