# ASHEN VAULTS — v0.7.1 «Охотники глубин»

*Доработка ИИ, мини-боссов и враждебных лагерей*

## Поведение врагов

- Противники запоминают последнюю видимую позицию героя на **3,5 секунды** и могут продолжать поиск за углом.
- Навигация по коридорам использует BFS с учётом видимости.
- Союзники передают друг другу информацию о цели на небольшом расстоянии; некоторые виды умеют обходить, уклоняться и держать дистанцию.
- Бандиты и монстры сражаются между собой, включая попадания снарядов.
- Щитоносцы и бронированные враги лучше защищены от фронтальных атак.
- Вооружённые зомби сохраняют свой тип, а не превращаются визуально в бандитских лучников.

## Семь специальных мини-боссов

| Мини-босс | Способность |
| --- | --- |
| Могильный мясник | Широкий веер из пяти ударов на ближней дистанции |
| Костяной лучник | Тройной залп |
| Гнилая ведьма | Пять отравляющих снарядов |
| Каменный страж | Радиальная ударная волна |
| Кровавый разоритель | Рывок с веером клинков |
| Шлаковый шаман | Восемь огненных направлений |
| Железный тиран | Плотный металлический залп |

У каждого свой интервал способности; при низком HP атаки становятся чаще.

Костяной регент получил вызов подкрепления, Тиран кузни — раскалённые зоны, Хранитель хранилища — манёвр во второй фазе.

## Комнаты и добыча

Лагерь бандитов окружён стенами и воротами, открывающимися при взаимодействии. Дополнены петли коридоров, укрытия и три типа ловушек: шипы, огненные выбросы и дротики.

Снаряжение врагов получило дополнительные эффекты: броня снижает входящий урон, лук открывает дистанционную атаку, зачарованное оружие усиливает удары. Подбираемые предметы в этой версии дают простые бонусы герою.

## Отображение

Для 23 новых типов противников подготовлены программные 16×16 силуэты и два кадра движения. Дополнены маркеры элиты, экипировки и подготовки атаки. Это **не** полноценные Paper2D-анимации.

Версия требует игровой проверки боевых коллизий, способностей и производительности в UE4.27.
