# ASHEN VAULTS v0.6.0 — Gameplay Expansion

**Engine:** Unreal Engine 4.27 / C++ (source-only). **Status:** code committed; full UE4.27 build and gameplay validation are still pending.

## New playable hero profiles
Press **H** to cycle heroes and restart the current run. Class selection intentionally resets the run to prevent mid-run stat exploits.

| Hero | HP | Stamina | Attack | Speed |
|---|---:|---:|---:|---:|
| Warden | 115 | 100 | 18 | 4.8 |
| Duelist | 82 | 120 | 22 | 5.7 |
| Arcanist | 75 | 135 | 16 | 4.6 |

These are **stat profiles**, not complete class kits: unique skills, class sprites and selection menu are still future work.

## Four enemy archetypes
- **Ash Reaver** (ID 11): fast melee, added to Crypt spawn table.
- **Spore Witch** (ID 12): ranged caster that retreats at short distance, added to Hollows.
- **Ember Knight** (ID 13): durable melee with increased reach, added to Foundry.
- **Cinder Specter** (ID 14): fast ranged caster, added to Foundry.

Existing enemy movement, targeting, hit registration and projectile behavior are reused. **Unique attack patterns and sprite art are not yet implemented.**

## Three collectible upgrades
- **Vitality Shard** (pickup 5): +12 max HP and heals 12.
- **Endurance Shard** (pickup 6): +10 max stamina and restores 10.
- **Haste Shard** (pickup 7): +0.18 movement speed.

After normal kills, the chance for one of these shards is **7.5%**; after boss kills **85%**. The shard type is chosen uniformly. Upgrades last until the end of the run. HUD-specific unique pickup sprites are not yet added.

## Implementation
- `AVContent.h/.cpp`: new hero profiles, enemy IDs 11–14 and updated biome spawn distribution.
- `AVGameMode.h/.cpp`: class cycling, hero initialization, collectible upgrade drops and pickup effects, ranged behavior for new casters.
- Existing combat loop, loot spawning, collision and map generator are reused.
